WeatherWise is a sophisticated web application that delivers hyper-local weather data with a focus on Indian meteorology. By integrating multiple data streams, it provides users with real-time atmospheric conditions, air quality monitoring, and precise 5-day forecasting through a minimalist, modern interface.

---

## ✨ Key Features

* **Real-Time Atmospheric Tracking:** Instant updates on temperature, high/low variance, and weather descriptions using the OpenWeatherMap data engine.
* **Integrated Air Quality Index (AQI):** A dedicated status engine that monitors and categorizes air pollution levels in real-time.
* **Dynamic 5-Day Forecast:** Automated daily temperature extraction to visualize upcoming weather trends.
* **Intelligent Search:** Quick-access search bar supporting global locations with a primary focus on Indian urban centers.
* **Premium Glassmorphism UI:** Built with a "frosted glass" aesthetic, featuring responsive design elements and high-definition mountain backdrops.

## 🚀 Technical Architecture

This project demonstrates proficiency in modern frontend development practices:

- **Asynchronous Data Handling:** Leverages the `Fetch API` with `Async/Await` patterns to handle concurrent requests to weather and pollution endpoints.
- **Dynamic DOM Manipulation:** Real-time interface updates without page refreshes, providing a "Single Page Application" feel.
- **Responsive Layout Engine:** Utilizes CSS Flexbox and `clamp()` functions to ensure a seamless experience across desktop and mobile viewports.
- **Data Range Logic:** Implements custom JavaScript algorithms to normalize temperature ranges when API reporting is static.
